Omniva / Betedesta — cPanel upload (no SSH)
===========================================

Zips in this folder (rebuild when shipping UI/API changes):
  1) api-esmusstrading.zip   → API (Laravel + vendor; keep live SQLite if already deployed)
  2) bono-static.zip         → Bono Mini App static for omniva.evella.et
     (EN/አማርኛ, button loading, native Mini App shell)

--------------------------------------------------
A) API — https://api.esmusstrading.com
--------------------------------------------------
1. In cPanel → Domains / Subdomains, open api.esmusstrading.com.
2. Set Document Root to:  .../omniva-api/public
   (create folder omniva-api first if needed)
3. File Manager → upload api-esmusstrading.zip into the parent of `public`
   (so paths look like: omniva-api/artisan, omniva-api/public/index.php).
4. Extract the zip. Delete the zip when done.
5. Permissions (File Manager → Permissions):
   - storage              755 (or 775)
   - storage/*            755/775
   - bootstrap/cache      755/775
   - database             755/775
   - database/database.sqlite  664
6. Open once in the browser:
   https://api.esmusstrading.com/cpanel-setup.php
   Then DELETE public/cpanel-setup.php in File Manager.
7. Check: https://api.esmusstrading.com/up

Demo logins (change passwords after first login):
  admin@omniva.test / Password123!
  cashier@omniva.test / Password123!
  waiter@omniva.test / Password123!

Staff can also sign in with phone (09… / +251…) once a phone is set on the account.

If the API is already live: do NOT overwrite database/database.sqlite when
refreshing code. Upload the new PHP files (or re-extract zip carefully), then
open cpanel-setup.php once so migrations run (unique phone + login support).

PHP (required): this app needs PHP 8.2+ (Laravel 12). PHP 8.1 will always fail.

  LiteSpeed / cPanel — try in order:
  1) MultiPHP Manager → api.esmusstrading.com → PHP 8.2 or 8.3 → Apply
  2) If you have "Select PHP Version" (CloudLinux): pick 8.2/8.3, enable
     pdo_sqlite, mbstring, openssl, tokenizer, json, ctype, fileinfo, curl, bcmath
  3) Re-upload public/.htaccess from the zip (it asks LiteSpeed for ea-php82)
  4) Recheck: https://api.esmusstrading.com/php-version.php

  If it still says 8.1.x → PHP 8.2 is not installed on the server.
  Open a host ticket: "Please enable ea-php82 (or lsphp82) for api.esmusstrading.com
  on LiteSpeed." You cannot run this API on 8.1.

  Do NOT run Composer on the server; vendor is already in the zip.
  Delete php-version.php and cpanel-setup.php after setup.

--------------------------------------------------
B) Bono static — https://omniva.evella.et
--------------------------------------------------
1. Document root = that site’s public_html (or domain root).
2. Upload bono-static.zip into public_html, extract, delete zip.
   Replace the whole site contents (old `/_nuxt/*` hashes break if mixed).
3. Keep the included .htaccess (SPA router).
4. BotFather Mini App URL: https://omniva.evella.et
5. Hard-refresh / clear Telegram WebView cache if you still see
   "500 Internal Server Error / 26" (that was a Mini App i18n crash, not the API).

API already baked in as: https://api.esmusstrading.com/api/v1

--------------------------------------------------
CORS
--------------------------------------------------
API .env already allows https://omniva.evella.et
If the static site uses another domain, edit omniva-api/.env
CORS_ALLOWED_ORIGINS and re-open cpanel-setup.php once (or clear
bootstrap/cache/config.php in File Manager).
